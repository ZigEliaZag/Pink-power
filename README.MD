Hello, I created my first ever milestone website project.


##### Name 
- The name of website is Dolomites.


This is travel recommendation for anyone who want to try new destination.
The website have only two pages which makes it easy to navigate.

###### website details and navigation
The whole web is made with three languages, html css and javascript.
* ###### Heeader 
On top left corner i have the name of website, it's clickable and direct user to homepage.  
On top right corner, it's navigation, for screens with 1024px up. I have to navigation to choose,
HOME if user have scrolled down and want to go back on top of page quick. GIVE FEEDBACK which direct user to feedback page. 
For screens with 768px up, I have a drop left menu. 
with ul li and 3 span translateY -10px and 10px adds line under and above, inside button i'm able to create a X shape like when button is clicked, 
span with 24px width and height of 3px will rotate -38 degree and 38 degree and make X shape when
 button is clicked to drag in menu which is translateX -100%. 
 When button is clicked again to remove menu, span goes back to it horizontal shape and menu is hidden.

* ###### Hero section  
 Hero section have a background image with a simple content wrap in div, given background color to match image a bit.

 * ###### Main content
 main is layed out in 3 layers of scetions apart from hero section which is include i main. 
 The first section layer is for the black background color and center other sections.
 The second section layer contain rest of other sections and it given max height of 80% 
 Third layer contain content and image as background. 

 * ###### Feedback page 
 This page have the same header as homepage. 
 On feedback page is user can give any feedback about the page or about the content. 
 The feedback form have input for user name and email, under email I have textaria where user can write feedback. 
 When user click the submit button, they see a message that their feedback was submit correcty
